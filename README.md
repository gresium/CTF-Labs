
# CTF-Labs

Author: Gresa Hisa

---

This repository contains all my hands-on security work across CTF platforms, guided lab environments, and self-directed technical investigations. Everything is documented — the commands, the methodology, what worked, what did not, and the conclusions drawn from each exercise. The goal is not just to complete challenges but to understand the underlying techniques well enough to explain and defend against them.

The repository is divided by platform and subject area. Each section has its own folder structure, and each individual lab or machine has its own dedicated writeup and supporting files. Nothing is shared or mixed between categories — if it belongs to HackTheBox, it is in HackTheBox, with its own documentation.

---

## HackTheBox

Machines and challenges organized by starting point and difficulty level. The Starting Point track (0, 1, 2) covers foundational machines designed to build core enumeration and exploitation skills progressively. Beyond that, easy-rated machines and standalone challenges each have their own folders containing full writeups — reconnaissance, enumeration, exploitation path, privilege escalation, and post-exploitation documented step by step.

## TryHackMe

A combination of guided labs, challenge rooms, and structured learning paths. Challenges are categorized by difficulty. Learning paths document completed modules with key techniques and takeaways from each. The regular labs section covers specific topic areas such as network traffic analysis, web application security, privilege escalation, and active directory fundamentals — each with its own notes and command reference.

## Labs

Standalone technical investigations and lab writeups covering full workflows from start to finish. This includes work done against my own infrastructure, domains I own, and systems I had explicit permission to test — as well as structured labs built around intentionally vulnerable environments. Each investigation is treated the same way: documented properly with full methodology, tools, commands, and findings.

Areas covered:

- Reconnaissance and OSINT — passive and active information gathering against real and simulated targets, including work against my own domain (securedefense.ch)
- Vulnerability Assessment and Penetration Testing — structured assessment methodology against intentionally vulnerable web applications
- Malware Analysis and Defense — payload generation, static analysis, VirusTotal detection, and network-level behavior monitoring
- Digital Forensics and Steganography — disk imaging, file recovery, and steganographic data extraction using forensic tooling

Each lab contains the full writeup, any scripts or commands used, and relevant output or evidence files.

---

All activity was performed legally — against intentionally vulnerable systems, platforms built for security training, or infrastructure I own or had explicit written permission to test.
